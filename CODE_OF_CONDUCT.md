# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be welcoming, be kind, critique ideas rather than people, and don't
harass anyone. That applies in issues, pull requests, discussions and anywhere
you represent the project.

## Reporting

Report anything that breaks this code privately to the maintainers listed in
[MAINTAINERS.md](MAINTAINERS.md). Reports are handled in confidence, and the
maintainers will follow the Contributor Covenant's enforcement guidelines.
